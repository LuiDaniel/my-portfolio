## Editor y sistema

- **Visual Studio Code**, mi editor para todo.
- **Windows 11** con Git Bash y PowerShell como terminales.
- **Git** y **GitHub** para el control de versiones.

## Lenguajes y entornos

- **Python 3.13**, para Django y scripts.

- **Go**, para APIs con Fiber.
