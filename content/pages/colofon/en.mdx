## Stack

Next.js (App Router) with React and TypeScript, Tailwind CSS v4, next-intl for Spanish and English and Velite for JSON and MDX content.

## The robot

Modeled, rigged and animated with Python scripts in Blender, exported to glTF with Draco and animated on the web with Three.js and GSAP.

## Design

Inspired by Apple's visual language (glass, large type, motion without bounce) with bento cards. Typefaces: Inter and JetBrains Mono.

## Quality

ESLint, Prettier, Vitest, Playwright and axe on every change, with GitHub Actions.
