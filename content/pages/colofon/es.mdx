## Stack

Next.js (App Router) con React y TypeScript, Tailwind CSS v4, next-intl para español e inglés y Velite para el contenido en JSON y MDX.

## El robot

Modelado, riggeado y animado con scripts de Python en Blender, exportado a glTF con Draco y animado en la web con Three.js y GSAP.

## Diseño

Inspirado en el lenguaje visual de Apple (cristal, tipografía grande, movimiento sin rebotes) con tarjetas tipo bento. Tipografías: Inter y JetBrains Mono.

## Calidad

ESLint, Prettier, Vitest, Playwright y axe en cada cambio, con GitHub Actions.
